调度与故障切换

当前生效的选路规则

  1. 校验账号与所属分组均已启用。
  2. API 密钥绑定分组时只在该分组内选号；该分组没有可用账号即直接失败，不会外溢。
  3. 未绑定分组的密钥：优先用模型映射指定的分组，无可用账号时回退到同服务商其他分组。
  4. 先比较分组优先级，再比较账号优先级，数值越小越优先。
  5. 同优先级下，计费倍率低的账号优先，倍率相同再看错误率。
  6. 按统计窗口内的错误率和错误次数熔断异常账号。
  7. 同等条件下按最近使用时间分散请求。
  8. 上游返回 408 / 425 / 429 / 5xx 或网络超时时自动切换账号重试。
